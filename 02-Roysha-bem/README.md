# 02_CSS設計とBEM

1.CSSアーキテクチャ<br>
「CSSは書くのは簡単だが、保守するのは最も難しい言語」<br>
CSSにある性質→「すべてのスタイルがグローバル(Webページ全体に影響する)」<br>
<br>
[起こりうる問題]<br>
- 詳細度のインフレ：スタイルが当たらなくなり、.main section ,div.box , .title span のようにセレクタをどんどん長くして無理やり適用させる。<br>
- !important の泥沼化：最終手段として !important を使い始め、後からそのスタイルを打ち消すために別の !important を重ねる悪循環に陥る。<br>
- デグレ（意図しない破壊）：あるページのデザインを直したはずが、関係ない別のページのレイアウトが崩れてしまう。<br>
- 不要コードの肥大化：下手に消すとどこが崩れるか分からない恐怖から、古いコードを消せず、下へ下へと修正用CSSを追記し続けてファイルが肥大化する。<br>
<br>
こうした問題を防ぎ、数ヶ月後の自分やチームの誰もが安全に修正・拡張できる状態を保つための計画と設計を「CSSアーキテクチャ（CSS設計）」<br>
